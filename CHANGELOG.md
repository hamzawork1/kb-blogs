# Changelog

All notable changes to **mhamza.space** are documented in this file.

Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) · Versioning: site is unversioned, releases are tracked by date.

## [Unreleased]

### Added
- Initial project documentation set:
  - `CHANGELOG.md` (this file).
  - `docs/decisions/` — architecture decision records (ADRs).
  - `docs/runbooks/` — operational how-tos (deploy, new post workflow).
- GitHub Actions CI/CD pipeline (`.github/workflows/ci-cd.yml`):
  - `build` job runs on every PR + push to `main`/`staging` — pnpm install,
    Biome lint, Astro build, Pagefind index verification.
  - `deploy` job runs on push to `main`/`staging`, runs `wrangler deploy
    --env <env>` to push `dist/` to a Cloudflare Worker with static assets.
    Production deploys come from `main` (Worker: `mhamza-space`); staging
    deploys to a separate Worker (`mhamza-space-staging`).
  - Requires repo secrets `CLOUDFLARE_API_TOKEN` (scope `Workers
    Scripts:Edit`) and `CLOUDFLARE_ACCOUNT_ID`.
- `wrangler.toml` at repo root declaring the production and staging
  environments and `[assets]` config pointing at `./dist`.

### Changed
- `docs/runbooks/deploy-cloudflare-pages.md` rewritten for the
  Actions-driven, Workers-with-static-assets deploy flow (Cloudflare's
  modern successor to Pages). See ADR 0003 for the full rationale,
  including why we lean into Workers over Pages.

## [2026-05-23]

### Added
- Bootstrapped personal site on the [Spectre](https://github.com/louisescher/spectre) Astro theme.
- First blog post: **Azure VM Public IP Upgrade — Basic SKU to Standard SKU**.
- Tag-based reusable cover banner system at `src/content/assets/<tag>-cover.png`, generated by `scripts/generate-covers.ps1` (7 tags: azure, devops, kubernetes, terraform, ci-cd, notes, guide).
- Branch strategy documented in `README.md`: `main` (production) ← `staging` (pre-prod) ← topic branches.

### Changed
- Customised theme branding to **Muhammad Hamza · mhamza.space**.
- Switched from npm to **pnpm** (`pnpm-lock.yaml` is the sole lockfile; `package-lock.json` removed).
- Removed `@astrojs/node` adapter — site is fully static for Cloudflare Pages.
- Replaced placeholder profile photo (purple ghost) with real headshot.
- Hid Spectre's article title pill background; title now renders over the cover banner with a subtle text shadow for legibility.

### Removed
- All Spectre theme demo content (`getting-started.mdx`, `spectre.mdx` project, theme cover image).
- Initial commit history squashed — single clean root commit; theme commit no longer in history.
